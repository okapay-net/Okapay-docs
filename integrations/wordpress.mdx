A dedicated Okapay plugin for WordPress and WooCommerce is in active development. When it launches, it will offer a no-code setup path for accepting payments directly from your WordPress admin — no custom PHP required.

<Note>
  The Okapay WordPress plugin is **coming soon** and is not yet available for installation. Until it is released, use the [Okapay PHP SDK](/integrations/php) to integrate payments into your WordPress theme or a custom plugin.
</Note>

## Accept Payments Today with the PHP SDK

You can start accepting payments on your WordPress site right now by using the Okapay PHP SDK inside a [custom WordPress plugin](https://developer.wordpress.org/plugins/intro/) or your theme's `functions.php`. The SDK gives you full access to the Products API and Checkout Sessions API from any server-side PHP context.

<Card title="PHP Integration Guide" icon="php" href="/integrations/php">
  Install the Okapay PHP SDK with Composer and start managing products and creating checkout sessions in plain PHP — no plugin required.
</Card>

## What to Expect from the Plugin

Once released, the WordPress plugin will be available in the WordPress plugin directory. It is designed to cover the following use cases:

- **WooCommerce checkout** — Okapay appears as a payment option on the WooCommerce checkout page
- **Standalone payment forms** — accept payments on any page without WooCommerce
- **No-code configuration** — enter your API keys in the WordPress admin settings panel

<Info>
  Want to be notified when the plugin launches? Check the [Okapay changelog](https://okapay.net/changelog) or watch the [GitHub repository](https://github.com/pkpayplus/pkpayplus-php) for announcements.
</Info>
